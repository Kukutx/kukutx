# 威胁模型

## 关键资产

- Firebase 身份、会话和设备记录。
- 邮箱、手机号、简历、申请、聊天和认证材料。
- 组织成员关系、招聘权限和管理员权限。
- 审计、处罚、付款标识和安全日志。

## 信任边界

- 客户端与 API。
- API 与 Firebase、对象存储、邮件、支付和地理编码供应商。
- 公共内容与私有/高度受限媒体。
- 普通用户、组织成员、审核员和管理员。

## 主要威胁与控制

- IDOR/越权：API 资源级授权、组织边界过滤和自动化回归测试。
- Token 盗用：验证发行者/受众/撤销状态、设备管理、敏感操作重认证。
- 重复提交：Idempotency-Key、唯一索引和事务 Inbox。
- 文件攻击：直传授权、文件头校验、隔离、扫描和短时签名 URL。
- 招聘骚扰：业务关系建会话、配额、Block、举报和组织处罚。
- 管理员滥用：最小权限、MFA、分权、敏感字段遮罩和不可覆盖审计。
- 日志泄漏：禁止记录 Token、完整联系方式、简历正文和认证材料。
