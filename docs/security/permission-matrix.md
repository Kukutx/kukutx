# 权限矩阵

| 能力 | User | Org Viewer | ContentManager | Recruiter | Admin | Owner | Platform Moderator | Platform Admin |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 读取自己的账户 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| 更新自己的资料 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| 查看组织资料 | 公开范围 | ✓ | ✓ | ✓ | ✓ | ✓ | 案件范围 | ✓ |
| 管理组织内容 | - | - | ✓ | - | ✓ | ✓ | - | ✓ |
| 管理职位和申请 | - | - | - | ✓ | ✓ | ✓ | 举报范围 | ✓ |
| 管理成员 | - | - | - | - | ✓ | ✓ | - | ✓ |
| 转移 Owner | - | - | - | - | - | MFA + 重认证 | - | 受审计支持 |
| 审核认证/内容 | - | - | - | - | - | - | ✓ | ✓ |
| 修改权限配置 | - | - | - | - | - | - | - | MFA + 分权 |

最终授权使用 RBAC + ABAC：角色授予能力，资源归属、组织状态、认证状态、Block、Suspension 和案件分派进一步限制访问。
