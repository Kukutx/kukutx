# 数据分类与字典

| 分类 | 示例 | 访问 | 主要控制 |
|---|---|---|---|
| Public | 公开职位、商家、帖子 | 公开 | CDN/缓存、内容审核 |
| Internal | 运营备注、聚合指标 | 员工最小权限 | 审计、导出限制 |
| Confidential | 邮箱、手机号、申请、聊天 | 本人和业务授权方 | 加密、脱敏、保留期 |
| Highly Restricted | 简历、认证材料、身份材料、支付标识 | 明确用例和提升权限 | 私有存储、短时 URL、访问审计 |

时间统一以 UTC 存储；业务时区使用 IANA ID。金额使用最小货币单位与 ISO 货币代码。电话号码规范化为 E.164。
