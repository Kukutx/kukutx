# 用户角色与关键旅程

## 角色

- 普通用户：浏览本地内容、商家和活动，发布与互动。
- 求职者：维护职业资料与简历，搜索并申请职位。
- 招聘者：代表已认证组织发布职位和管理候选人。
- 组织所有者/管理员：管理组织、成员、权限和认证。
- 内容管理员：维护组织内容、商家和活动。
- 平台审核员：处理认证、职位、内容、举报和申诉。
- 平台管理员：管理配置、权限、审计和运营队列。

## 首批闭环

1. 用户通过 Firebase 登录。
2. API 验证 Token，并以 Firebase UID 幂等创建业务账户。
3. 用户读取并更新昵称、语言、时区和城市。
4. 后续切片接入组织创建、认证、职位发布和申请。
